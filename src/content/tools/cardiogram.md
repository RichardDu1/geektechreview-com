Cardiogram uses the DeepHeart neural network to analyze heart rate data from Apple Watch, Fitbit, and other wearables. It provides a daily AFib probability score and can alert users to potential arrhythmias. The clinician dashboard allows remote monitoring of patients. It's HIPAA-compliant and integrates with EHRs via FHIR.
