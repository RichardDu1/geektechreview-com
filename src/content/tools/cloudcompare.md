CloudCompare is a powerful free tool for point cloud analysis. Use the CSF filter to classify ground points, then compute DEM and DSM differences for volume. It handles large LAS files from Pix4D. The plugin for raster export (GeoTIFF) is essential. While the UI is dated, the functionality is unmatched for the price.
