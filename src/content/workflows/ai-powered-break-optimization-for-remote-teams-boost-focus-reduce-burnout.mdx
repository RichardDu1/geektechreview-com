## Overview

This workflow uses wearable EEG headbands (Muse) to collect real-time stress and focus data, then automates break scheduling via Zapier and Google Calendar. Notion serves as a dashboard for team insights.

## Prerequisites

- **Muse S Headband** (or similar EEG wearable) – $249
- **Zapier** account (Free tier works)
- **Google Calendar** (free)
- **Notion** (free)

## Step 1: Set Up Muse Data Collection

1. Download the **Muse** app on your phone.
2. Pair your Muse headband via Bluetooth.
3. Enable **Focus** and **Stress** metrics in the app settings.
4. Ensure data syncs to Muse’s cloud (requires account).

## Step 2: Connect Muse to Zapier

1. Log in to [Zapier](https://zapier.com).
2. Create a new Zap: **Trigger: Muse** → **New Session Data**.
3. Connect your Muse account (use OAuth).
4. Test trigger to pull sample data (stress level, focus score).

## Step 3: Build AI Decision Logic

1. Add a **Filter** step: Only continue if stress > 70 OR focus < 30 (scale 0-100).
2. Add a **Code by Zapier** step (Python):
   - Input: `stress`, `focus`
   - Code:
     ```python
     if input_data['stress'] > 70:
         break_duration = 15  # minutes
     elif input_data['focus'] < 30:
         break_duration = 10
     else:
         break_duration = 5
     return {'duration': break_duration}
     ```
3. Output: `duration` (minutes).

## Step 4: Schedule Break in Google Calendar

1. Add **Google Calendar** action: **Create Detailed Event**.
2. Set:
   - Calendar: Your work calendar
   - Title: "AI-Recommended Break"
   - Start Time: `Now` (use `{{zap_meta_human_now}}`)
   - Duration: `{{duration}}` minutes
   - Description: "Stress: {{stress}}, Focus: {{focus}}"
3. Test and turn on Zap.

## Step 5: Log to Notion Dashboard

1. Create a Notion database with columns: `Date`, `Stress`, `Focus`, `Break Duration`.
2. Add **Notion** action in Zapier: **Create Database Item**.
3. Map fields from Muse and Code step.
4. View dashboard to track team trends.

## Step 6: Team Deployment

1. Each team member sets up their own Muse + Zapier (use template).
2. Share Notion dashboard with manager.
3. Review weekly: adjust thresholds if needed.

## Tips

- Use **Muse's real-time API** for live adjustments (advanced).
- Combine with **Pomodoro technique** for structured breaks.
- Ensure privacy: anonymize data in shared dashboards.
