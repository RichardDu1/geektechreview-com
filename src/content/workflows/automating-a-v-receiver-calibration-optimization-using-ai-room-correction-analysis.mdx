## Overview

This workflow guides home theater installers through automating A/V receiver calibration using AI room correction analysis. By combining measurement tools like REW with advanced room correction suites (Dirac Live, Audyssey MultEQ-X), you can achieve consistent, optimized results faster than manual methods.

## Prerequisites

- A/V receiver with room correction support (e.g., Denon, Marantz, NAD, Arcam)
- Measurement microphone (e.g., MiniDSP UMIK-1)
- Laptop with Windows/macOS
- Software: REW (Room EQ Wizard), Dirac Live or Audyssey MultEQ-X
- Optional: calibrated SPL meter

## Step 1: Set Up Measurement Environment

1. **Position the microphone** at the primary listening position (ear height, pointed at ceiling).
2. **Ensure quiet ambient noise** (HVAC off, doors closed).
3. **Connect microphone** via USB to laptop.
4. **Open REW** and configure input/output devices.

## Step 2: Capture Room Acoustic Data

1. In REW, set sweep parameters: 20Hz-20kHz, 1/48 octave smoothing.
2. Run a **sweep measurement** and save the .mdat file.
3. Repeat at 3-5 additional listening positions (optional for multi-seat calibration).
4. Export the measurement as a .txt or .frq file for import into room correction software.

## Step 3: Import into AI Room Correction Software

### For Dirac Live:
1. Open Dirac Live and create a new project.
2. Import the REW measurement file (or use Dirac's own measurement wizard).
3. Set target curve: flat from 20Hz-500Hz, gentle roll-off above 500Hz (or use Dirac's automatic target).
4. Enable **Bass Control** (if supported) for multi-sub optimization.
5. Let AI compute filters; review and adjust manually if needed.

### For Audyssey MultEQ-X:
1. Open MultEQ-X and load the Audyssey calibration file from the receiver.
2. Import REW measurements as reference.
3. Use **AI Room Correction** to generate custom filters.
4. Adjust target curve and apply **Dynamic EQ** settings.

## Step 4: Apply and Verify

1. Export the filter file and upload to the A/V receiver via USB or network.
2. Run a final REW measurement to verify frequency response.
3. Check for **bass nulls** and adjust subwoofer placement if needed.
4. Perform a listening test with known reference material.

## Step 5: Automate for Repeatability

1. Save measurement templates in REW for similar room sizes.
2. Use **Dirac Live's batch processing** or **Audyssey's scripting** to apply presets.
3. Document the process in a checklist for consistent results across jobs.

## Troubleshooting

- **Phase issues**: Use REW's impulse response to check polarity.
- **Over-correction**: Limit correction range to 500Hz to avoid artifacts.
- **Subwoofer integration**: Use Dirac's Bass Control or Audyssey's Sub EQ HT.

## Conclusion

By automating calibration with AI room correction, installers save time and deliver superior sound quality. This workflow reduces human error and ensures every installation meets reference standards.
